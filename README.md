## ✨ امکانات

### استودیوی عکس + خطایابی بازی + مدیریت API + ۸ بخش تنظیمات (جدید در 1.6.0)
- 🖼 **استودیوی حرفه‌ای ساخت عکس**: توضیح فارسی یا انگلیسی + ۸ سبک (واقع‌گرایانه، انیمه، دیجیتال آرت، آبرنگ، پیکسل‌آرت، سه‌بعدی، آرت بازی) + گالری «ساخته‌های اخیر» + ذخیره + **پیوست تصویر به گفتگو** تا درباره‌اش سؤال کنی — با API واقعی (Flux کلادفلر + پولینیشن رایگان؛ بدون هیچ تصویر ساختگی)
- 🎮 **خطایابی بازی مثل یک IDE**: خطاهای اجرای بازی زنده در پنل قرمز نمایش داده می‌شود + دکمهٔ **«رفع خطا با سوکوت»** که کد و خطا را یک‌جا برای تعمیر می‌فرستد + **ویرایشگر کد** داخل اجراکننده با اجرای مجدد
- 🧩 **بخش مستقل «مدیریت API»**: ارائه‌دهنده، کلید، Base URL، نام مدل، تست اتصال با **خطاهای دسته‌بندی‌شده** (احراز هویت / محدودیت درخواست / اتصال / مدل) + حذف API ذخیره‌شده + توضیح امنیت کلیدها
- 🗂 **تنظیمات ۸ بخشی**: عمومی · ظاهر و تم · مدل هوش · مدیریت API · ساخت عکس · بازی‌سازی · امنیت و حریم خصوصی · درباره — با کارت‌های مرتب و سازگار با موبایل
- 🎨 **۳ تم واقعی**: شبِ بنفش، اقیانوس آبی، روشن + **اندازهٔ متن پیام‌ها** + حالت کم‌انیمیشن
- 🛡 **حریم خصوصی**: پاک‌کردن گفتگوها / حافظه / همهٔ داده‌ها با تأیید دومرحله‌ای — کلیدها فقط روی دستگاه خودت می‌مانند

### ساخت عکس + استودیوی بازی + سرویس‌های رایگان بدون کارت (1.5.0)
- 🎨 **ساخت عکس مثل ChatGPT**: دکمهٔ «عکس» کنار نوشتار را روشن کن و بنویس چه چیزی بسازد — سوکوت عکس می‌سازد، نمایش می‌دهد و می‌توانی **ذخیره‌اش** کنی (اندروید: گالری در `Pictures/Sukot`، ویندوز: پوشهٔ Downloads)
- 🆓 **موتور عکس رایگان بدون کلید**: موتور **پولینیشن (Pollinations.ai)** هیچ کلید و ثبت‌نامی نمی‌خواهد و در هر سه نسخهٔ اندروید/ویندوز/وب کار می‌کند؛ اگر کلادفلر تنظیم باشد خودکار از **Flux-1-Schnell** کلادفلر استفاده می‌شود و اگر جواب نداد خودکار به موتور رایگان برمی‌گردد
- 🎮 **استودیوی بازی‌سازی + اجرای زنده**: دستیار تخصصی «بازی‌سازی» بازی کامل HTML5 می‌سازد و روی هر بلوک کد دکمهٔ **«اجرای بازی»** می‌آید — بازی همان‌جا داخل اپ در محیط ایزتهٔ امن (sandbox) اجرا می‌شود؛ تمام‌صفحه هم دارد
- 🌍 **سرویس‌های رایگانِ بدون کارت بانکی** (در تنظیمات، تب «اتصال»): **پولینیشن** (بدون حتی ثبت‌نام)، **Groq** (فقط ایمیل — سریع‌ترین سرور دنیا)، **Google Gemini** (کلید رایگان از AI Studio) + OpenRouter و Cloudflare
- 🧩 **API خارجی دلخواه**: بخش مخصوص در تنظیمات — هر سرویس سازگار با OpenAI (Ollama، LM Studio، پروکسی شخصی…) را با آدرس + کلید + مدل وصل کن
- 🗂 **تنظیمات ۵ تبه شد**: اتصال و API خارجی · ساخت عکس · جستجو و ابزار · صدا · پاسخ و شخصیت — دیگر شلوغ نیست
- ✍️ املای درست نام: «**سوکوت**» در همه‌جا اصلاح شد

### آپلود فایل و عکس + غول‌های بالای ۳۰۰B (1.4.0)

- 👁 **سوییچ خودکار به مدل بینا**: اگر عکس بفرستی و مدل فعلی تصویر نبیند، خودکار به Llama 4 Scout می‌رود و توضیح می‌دهد

## 🚀 راه‌اندازی (۳ دقیقه)

1. فایل APK یا EXE را از [Releases](../../releases) نصب کن (یا پوشه `web` را روی هاست بگذار)
2. در پنل کلادفلر: `dash.cloudflare.com` → **Workers AI** → **Use REST API** → توکن و **Account ID** را کپی کن
3. در ربات روی **تنظیمات** بزن، توکن و Account ID را وارد کن → **ذخیره** → **تست اتصال**
4. تمام! حالا هر سوالی داری بپرس ✨

> 💡 توکن باید دسترسی **Workers AI — Edit** داشته باشد. اگر هنگام ساخت توکن گزینهٔ «IP Address Filtering» فعال بود، آن را حذف کن وگرنه خطای `9109` می‌گیری.

## 🛠 ساخت از سورس

```bash
# اندروید (نیاز به JDK 17 و Android SDK)
gradle -p android assembleDebug
# خروجی: android/app/build/outputs/apk/debug/app-debug.apk

# ویندوز (نیاز به Node 20)
cd electron && npm install && npm run dist
# خروجی: electron/dist/Sukot-AI-Bot-Setup-1.5.0.exe + نسخهٔ Portable
```

بیلد هم به‌صورت خودکار با GitHub Actions انجام می‌شود — هر push به `main` یک APK و EXE تازه می‌سازد (تب Actions).

## 🌐 نسخهٔ وب (اختیاری)

مرورگرها به‌خاطر سیاست CORS نمی‌توانند مستقیم به `api.cloudflare.com` وصل شوند. نسخهٔ اندروید و ویندوز این مشکل را با پل بومی (Native Bridge) دور می‌زنند. اگر نسخهٔ وب را می‌خواهی:

1. در کلادفلر: **Workers & Pages → Create → Worker**
2. محتوای فایل [`worker/worker.js`](worker/worker.js) را داخلش Paste کن و Deploy بزن
3. در تنظیمات ربات، «آدرس API» را بگذار: `https://<your-worker>.workers.dev/cf/<ACCOUNT_ID>`

## 🧪 تست محلی بدون کلادفلر

```bash
node scripts/mock-cf-server.js 8787
# سپس http://127.0.0.1:8787 را باز کن
```
